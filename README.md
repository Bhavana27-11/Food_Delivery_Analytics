# Food Delivery Analytics

## Project Overview

This project analyzes food delivery data using Python, SQL and Power BI to identify business trends, customer behavior and operational performance.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- SQL
- MySQL
- Power BI
- Power Query
- DAX

## Key KPIs

- Total Orders
- Total Revenue
- Average Order Value
- Average Customer Rating
- Complaint Rate
- Refund Rate
- Churn Risk
- Demand Score
